Selected Data Science Projects

SPATIAL MODEL
Python GeoPandas GEE

Spatial Modeling of Malaria Prevalence in Western Endemic Zone of Kenya

Bayesian geospatial modelling of malaria using DHS survey microdata and Google Earth Engine satellite covariates.

  • Built Bayesian geostatistical models (Python Pymc) to smooth small-area estimates.
  • Integrated environmental rasters (NDVI, temperature, rainfall) as model covariates via GEE.
  • Developed malaria prevalence risk maps using python pymc.
GitHub Live Demo Report
REMOTE SENSING · DL
PyTorch GEE Python U-Net

Urban Green Space Change Detection using Deep Learning In Progress

A deep learning pipeline for detecting and quantifying temporal changes in urban green space across Nairobi and other East African cities using multi-temporal satellite imagery from Google Earth Engine.

  • Developing a U-Net segmentation model trained on Sentinel-2 and Landsat-9 imagery to classify green cover at 10m resolution.
  • Building a change detection module to track green space loss and gain between 2015 and 2024 across major urban corridors.
  • Integrating outputs with socioeconomic indicators to analyse environmental equity patterns across city neighbourhoods.
